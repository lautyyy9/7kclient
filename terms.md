Bienvenido a 7K CLIENT.

Al utilizar el bot de Discord 7K CLIENT, aceptas estos Términos de Servicio.

1. Uso del servicio

7K CLIENT es un bot de soporte para la aplicación 7K CLIENT destinada a HaxBall. Sus funciones incluyen, entre otras:

Sistema de tickets.
Moderación.
Asistencia mediante inteligencia artificial.
Gestión de descargas y licencias de la aplicación.
2. Uso permitido

Al utilizar el bot aceptas no:

Utilizar el servicio para actividades ilegales.
Enviar spam o contenido malicioso.
Intentar vulnerar la seguridad del bot.
Abusar de las funciones de IA o del sistema de tickets.

El incumplimiento podrá resultar en la suspensión o bloqueo del acceso al servicio.

3. Pagos

Algunas funciones o descargas pueden requerir un pago.

Los pagos realizados corresponden al acceso a la aplicación y sus servicios según las condiciones publicadas por el propietario.

El servicio se proporciona "tal cual". No se garantiza disponibilidad permanente ni funcionamiento ininterrumpido.

El propietario podrá modificar, actualizar o eliminar funciones en cualquier momento.

5. Limitación de responsabilidad

El propietario de 7K CLIENT no será responsable por daños directos o indirectos derivados del uso del bot o de la aplicación.

6. Cambios

Estos términos pueden modificarse en cualquier momento. El uso continuado del bot implica la aceptación de las versiones actualizadas.

Política de Privacidad

Política de Privacidad de 7K CLIENT

Última actualización: 2 de agosto de 2026

La privacidad de los usuarios es importante para nosotros.

Información recopilada

El bot puede recopilar la siguiente información necesaria para su funcionamiento:

ID de usuario de Discord.
ID de servidor.
ID de canal.
ID de roles.
Configuración del servidor.
Información relacionada con los tickets creados.
Información necesaria para administrar licencias o acceso a la aplicación.
Uso de la información

Los datos recopilados se utilizan exclusivamente para:

Proporcionar soporte.
Gestionar tickets.
Moderar servidores.
Administrar licencias y descargas.
Mejorar el funcionamiento del bot.
Resolver incidencias.
Inteligencia Artificial

Si utilizas funciones de IA, el contenido enviado podrá procesarse para generar respuestas. Ese contenido solo se utilizará para prestar el servicio correspondiente.

Compartición de datos

No vendemos ni compartimos datos personales con terceros, salvo cuando sea necesario para el funcionamiento del servicio o cuando la ley lo exija.

Seguridad

Se aplican medidas razonables para proteger la información almacenada. No obstante, ningún sistema es completamente seguro.
