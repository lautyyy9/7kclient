Política de Privacidad

Política de Privacidad de 7K CLIENT

Última actualización: 2 de agosto de 2026

La privacidad de los usuarios es importante para nosotros.

Información recopilada

El bot puede recopilar la siguiente información necesaria para su funcionamiento:

ID de usuario de Discord.
ID de servidor.
ID de canal.
ID de roles.
Configuración del servidor.
Información relacionada con los tickets creados.
Información necesaria para administrar licencias o acceso a la aplicación.
Uso de la información

Los datos recopilados se utilizan exclusivamente para:

Proporcionar soporte.
Gestionar tickets.
Moderar servidores.
Administrar licencias y descargas.
Mejorar el funcionamiento del bot.
Resolver incidencias.
Inteligencia Artificial

Si utilizas funciones de IA, el contenido enviado podrá procesarse para generar respuestas. Ese contenido solo se utilizará para prestar el servicio correspondiente.

Compartición de datos

No vendemos ni compartimos datos personales con terceros, salvo cuando sea necesario para el funcionamiento del servicio o cuando la ley lo exija.

Seguridad

Se aplican medidas razonables para proteger la información almacenada. No obstante, ningún sistema es completamente seguro.
